# Портфолио-сайт (многостраничный)

Личный сайт-портфолио с проектами по разработке и аналитике данных.

## О проекте

Многостраничный сайт, созданный в рамках практики  
Страницы:

- `index.html` — главная страница с информацией обо мне и навигацией
- `code.html` — проекты по разработке (веб, приложения, утилиты)
- `analytics.html` — проекты по аналитике данных (дашборды, анализ, визуализация)

## Проекты

Здесь собраны учебные проекты, которые я реализую и решаю самостоятельно.  
Это упражнения, где я:

- формулирую задачу (решаемая проблема, реализуемый принцип или работа с библиотекой)
- проектирую решение
- реализую его с использованием HTML, CSS, JavaScript и инструментов аналитики

Каждый проект направлен на отработку конкретных навыков и решение «проблемы»:  
упростить процесс, визуализировать данные, автоматизировать рутину и т.п.

## Технологии

- HTML, CSS, JavaScript
- Адаптивная вёрстка
- Основы аналитики данных и визуализации

## Структура репозитория

- `index.html` — главная
- `code.html` — страница с проектами по разработке
- `analytics.html` — страница с проектами по аналитике
- `style.css` — общие стили

## Как посмотреть

Открыть `index.html` в браузере или включить GitHub Pages в настройках репозитория.
